# app/ (Mihika)

The Practify phone app: Expo (React Native, TypeScript, Expo Router), connected to
Convex, run on a phone through Revyl.

First Capy task: create the Expo app in this folder with the link scheme `practify`
set from the start, install `convex`, and wrap the app in `ConvexProvider` using
`EXPO_PUBLIC_CONVEX_URL`. Import the backend API from `../convex/_generated/api`.

Screens and their backend functions are in `PLAN.md` ("Screens").
